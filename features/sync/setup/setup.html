Save your recovery key

Store this key somewhere private, outside this browser profile. You need it to join another profile or recover after losing this device's key protection. Breezer cannot reset it. Anyone with the key and access to your vault can read its contents.

Recovery and transport limits

When a vault fails authentication, do not overwrite or recreate it. Check the provider and recovery key. Disconnecting and rejoining preserves your local saved data; reconnecting merges it with the vault. Deleted saved items remain deleted when an offline profile reconnects.

Sync needs a provider that supports exact revision checks. A local test provider is available for disposable-profile testing. It is not a hosted cloud service. Never enter your vault recovery key in a provider's web page or an AI chat.
