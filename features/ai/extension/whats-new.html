A little more your browser

Four changes in this release, and one thing that isn't ready yet.

Open Settings

New in this release

Bookmarks where you want them

Bookmarks appear on new and blank tabs by default. Choose New tabs only, Always or Hidden in Settings.

A calmer Settings page

Clearer controls, readable connection status and more space make Settings easier to use, including on narrow windows.

Bring Chrome along

The getting-started card explains importing Chrome bookmarks and history, plus the password CSV steps. Importing copies data once; it does not sync Chrome changes or import passkeys.

An AI sidebar that helps you recover

Failed replies offer Edit and resend to put your message back in the composer. Nothing is sent automatically, and browser control stays off until you enable it again.

Not yet: Touch ID passkeys

Website passkey sign-in with Touch ID still needs Apple-approved signing entitlements that Breezer does not have yet. This is separate from saving and filling passwords.
