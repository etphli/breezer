    Bookmarks and history

    Opens the import dialog in a new tab. Choose Google Chrome, then pick what to copy.

    Passwords

    1. In Chrome, open Password Manager, then Settings, and choose Export passwords.
    2. Back in Breezer, choose Import passwords and select the exported file.
    3. Delete the exported file afterwards, including from the Trash.
