# Breezer development tools

These tools check Breezer's inherited patch series, configuration, source files, and translations. Read each script's description for its arguments.

From the Breezer repository root, run the development-tool tests together with the build-tool tests:

```sh
.venv/bin/python script/check_helium.py
```

The scripts and tests were inherited from Helium and ungoogled-chromium. Their original licences and copyright notices remain in the source files. Breezer keeps the upstream tests intact.
