Install in three steps

  1. Drag Breezer into Applications

    Open the downloaded disk image and drag the Breezer icon onto the Applications folder.

  2. Allow it the first time

    Breezer isn't notarized by Apple yet, so macOS stops the first launch. Open System Settings, choose Privacy & Security, then select Open Anyway beside the Breezer message.

  3. Bring your Chrome data

    Breezer opens with a short guide in Settings for importing bookmarks, history and passwords.

Good to know

  • Intel Macs, Windows and Linux aren't supported yet.
  • Breezer keeps its own profile. Chrome stays exactly as it is.
  • After this, updates install from Breezer's Settings.
  • The assistant uses your own signed-in Codex or Claude command-line tool.

Breezer is open source under GPL-3.0, built on Helium and Chromium.
