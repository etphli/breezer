# Settings redesign evidence

Captured by `tests/ai/settings-redesign-browser.test.mjs` in headless Chrome against the browser API fixture (no native Breezer build). Desktop shots are 1200 × 860 CSS px, the narrow shot is 390 px wide; all were downscaled for the repository.

- `general-dark.png`: category list, breadcrumb and grouped rows in dark mode.
- `appearance-light.png`: theme previews and rows in light mode (Dusk applied).
- `search-light.png`: grouped results for “dark mode”, with the Chromium search fallback.
- `no-results-light.png`: the no-results state.
- `layout-narrow.png`: the 390 px layout with the scrolling category strip.
- `languages-dark.png`, `passwords-dark.png`: feature-owned settings (translation, passwords and passkeys) inside the new layout.
