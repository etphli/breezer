# Breezer

A personal browser project planned as a customised distribution of [Helium](https://github.com/imputnet/helium).

The goals are faster browsing, lower memory and energy use, and an interface shaped around Ethan's workflow. These are development goals, not measured results.

## Project status

Initial repository and branding setup. Browser development has not started, and no Breezer builds are available yet.

## Branding

The [Breezer logo](assets/branding/breezer-logo.png) is a full-resolution PNG with transparency around the app tile. The artwork was created with OpenAI's built-in image generation tool using the [saved prompt](assets/branding/logo-prompt.txt).

## Upstream

[Helium](https://helium.computer/) is the intended browser foundation. This repository does not yet contain Helium source code. Upstream code will retain its required licences and notices when imported.
